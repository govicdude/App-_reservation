## Le problème

- Problème : Prends beaucoup de temps, c'est difficile sur téléphone de compléter un document excel, répétition d'actions (ex: numéro Id), possibilité d'inaccessibilité du document excel. Parfois, le nom des objets sont un petit peu difficiles à comprendre( ne sait pas quoi réserver)

## La solution

- Proposition de valeur : Faire une liste de sélection pour chaque cours du programme tim contenant du matériels à emprunter. Quand un cours est sélectionné la liste des items du cours vont être. pour diminuer le temps utiliser à remplir le tableau, on peut déjà tous coché les près requis du cours, par exemple le sound device pour audio. Question de quel projet va être fait après, choisir automatiquement ce que t'a besoin pour le projet.
